How this worksData is read live from the state GIS services each time this page opens, so results always reflect the current records. Loading takes about 10–30 seconds.

2. iTAP export

No iTAP file loaded.
How this works Load iTAP's Search Results export as it comes (.xlsx, or saved as CSV). Nonextant counts as demolished, any Extant status as standing, Unknown as unknown. Bridges in the INDOT Select/Non-Select layers use that layer's location. Every other bridge in the file is placed with its NBI location (or, when it has been replaced, the replacement bridge's NBI location) and linked through the HB / IHSSI numbers iTAP has on file. It is matched to SHAARD by those numbers first, then by distance. These NBI bridges are shown only when they match a SHAARD record.

3. Match warning reviews

Not connected.
How this works For each row with a ⚠, record whether the records really are the same bridge. Reviews are saved online, so they stay when the page or the GIS data reloads. A review is cleared automatically if the row's records or its warnings change. Export for SHAARD lists the records whose status needs changing. A row with a warning is left out until it is reviewed as Same bridge.
