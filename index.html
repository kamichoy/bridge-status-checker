2. iTAP verification file (CSV)

No iTAP file loaded.
The Select/Non-Select layers don't record demolitions, so the iTAP result for each bridge is kept in a CSV you maintain in Excel. Download iTAP worksheet gives you every INDOT bridge with what SHAARD currently says, plus any iTAP entries already loaded. Fill in the iTAP Status column (Demolished, Standing or Unknown; iTAP's own Nonextant / Extant wording also works), save as CSV, and load it back here. You can also load iTAP's Search Results export (.xlsx) directly, no conversion needed. Only the NBI, iTAP Status, Checked On, Checked By and Note columns are read; other columns are ignored.
